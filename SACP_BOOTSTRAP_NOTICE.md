# SACP temporary bootstrap host

This otherwise-empty private repository is being used as a reversible staging host because the requested destination `doitupsolutions810-crow/sacp-platform` is not visible to the installed GitHub connector.

The canonical deliverable remains `sacp-platform`. Do not treat this repository name as the final architecture decision. The complete validated Git bundle and PR-ready source archive are staged here so they can be migrated without rebuilding history once the destination repository is available.

No production credentials, signing keys, or private key material are stored here.
